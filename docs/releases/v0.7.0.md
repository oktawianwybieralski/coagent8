# CoAgent8 0.7.0

CoAgent8 lets your coding agent ask local Codex, Claude Code and Antigravity
CLIs for a second opinion or an independent Git review. It runs through MCP,
using your installed and signed-in CLIs, with read-only execution profiles.
This version is a preview for testers.

## Install

Use Node.js 24 or later and at least one supported coding CLI. In VS Code,
install `okidev.coagent8-mcp` from the Marketplace, or use **Extensions: Install
from VSIX...** with `coagent8-mcp-0.7.0.vsix` from this release.

For the standalone CLI:

```bash
npm install -g coagent8@0.7.0
coagent8 --help
coagent8 doctor --scope health
```

To register the server in supported CLI chats:

```bash
npx -y coagent8@0.7.0 setup --clients=codex,claude,agy
```

## What changed

- The public CLI exposes help, diagnostics, model lists and session inspection.
  `coagent8 mcp` explicitly starts the MCP server; running `coagent8` in a
  terminal shows help.
- Client registrations use the explicit MCP command. Setup shares the user
  runtime between CLI chats and preserves manual entries and newer runtimes.
- Model selection under a price limit prefers newer eligible models. Doctor
  reports readiness from installation, sign-in and execution evidence, with
  fewer repeated catalog reads.
- Reviews can recover from partial coverage and read denials. CoAgent8 owns
  the review terminator and supports larger Codex review prompts. A P1 or P2
  finding blocks also when the reviewer omits its brackets.
- Changes to images and other binary files no longer block every review: they
  are listed for the reviewer, bound to the reviewed snapshot, and READY states
  how many binary files were not reviewed.
- Sessions of a deleted workspace can still be listed, read and closed.
- Bug reporting opens the issue form and provides a sanitized report to paste.
- Turn results include the token usage the backend reports and, when every
  needed count and price is known, an approximate public API list-price
  equivalent; that estimate is not your account's bill. agy reports no cache
  counts, so its turns show counts only.
- Setup writes retry transient sharing failures, history tail reads are bounded,
  and the observation cache has a size limit.

## Upgrade from 0.6.1

Install the new extension or standalone package, then restart the MCP server
in your client so it loads the updated runtime. Use `doctor` with health scope
to confirm the running version and backend readiness. Setup and repair migrate
owned registrations to the explicit `mcp` command; manually edited entries are
preserved. Legacy bare MCP registrations continue to work over piped stdio.
Configuration and sessions remain in the existing user directory.

## Known limitations

- Delegated agents cannot yet write changes, run checks or coordinate other
  agents. Reviews do not replace tests or owner acceptance.
- Antigravity inherits its configured MCP servers and plugins; its sandbox does
  not isolate those inherited tools. CoAgent8 refuses recursive turns.
- On Windows, a native descendant created outside the owned job can survive
  cancellation. Complete descendant containment is still pending.
- Codex can deny some workspace reads; incomplete or denied required review
  input must not be treated as approval.
- Native WSL acceptance and Open VSX distribution are deferred. Use the VS Code
  Marketplace or the release VSIX for this preview.
- Backend availability, model access and account billing follow your CLI account.
